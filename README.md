# WebCarrot 오프라인 설정 데모

[웹에서 열기](https://fullmetalsonic.github.io/webcarrot-offline-demo/) · [최신 HTML 다운로드](https://github.com/fullmetalsonic/webcarrot-offline-demo/releases/latest/download/webcarrot-offline-demo.html)

콤마에 연결하지 않고 WebCarrot 설정 메뉴를 살펴보고, 파라미터 백업 JSON을 편집하는 비공식 데모입니다. 원본 제작자의 공식 배포물이 아닙니다.

## 사용 방법

1. 웹에서 열거나 Release의 `webcarrot-offline-demo.html`을 내려받아 사용합니다. 내려받은 단일 HTML은 인터넷 없이 설정을 편집할 수 있습니다.
2. **도구 → JSON 백업 불러오기**에서 기존 백업을 선택합니다.
3. **설정**에서 분류와 그룹을 선택하거나 검색한 다음 값을 조절합니다. 차량은 제조사 → 모델 → 확인 순서로 선택합니다.
4. **도구 → 백업 JSON 내보내기**로 저장하고 공유합니다. 파일을 받는 사람이 콤마에서 복원해야 실제 설정에 적용됩니다. 차량 선택은 복원 후 재시작이 필요합니다.

처음 시작하는 데모는 원본 기본값을 사용합니다. 가져온 백업은 없는 항목을 임의 추가하거나 모르는 항목을 삭제하지 않습니다. 편집하지 않은 JSON 값의 형식과 중첩 구조도 유지합니다. 실제 차량 설정 변경·재부팅·터미널 명령은 수행하지 않습니다.

## 데모 업데이트

- 실행 시 GitHub의 최신 정식 Release를 백그라운드에서 확인합니다. **도구**에서 현재/최신 버전, 확인 상태와 수동 확인·업데이트 버튼을 볼 수 있습니다.
- 새 데모를 배포하면 파라미터, 설명, 메뉴와 화면이 함께 갱신됩니다. 원본 WIP의 모든 커밋을 자동 반영하지는 않습니다.
- 웹 버전은 업데이트 전 현재 백업을 브라우저에 임시 보관하고 새 화면에서 복원합니다. 중요한 편집값은 별도 JSON 파일로도 내보내세요.
- 내려받은 HTML은 자기 파일을 덮어쓸 수 없습니다. 업데이트 안내에서 백업 JSON을 저장하고 최신 HTML을 내려받은 뒤 백업을 불러옵니다.
- 인터넷 연결 실패, GitHub 호출 제한 또는 시간 초과가 발생해도 기존 설정 편집은 계속 사용할 수 있습니다. 사전 릴리스는 일반 업데이트에서 제외합니다.

## 원본과 차이

설정 정의 기준은 [ajouatom/openpilot carrot-wip `43203371`](https://github.com/ajouatom/openpilot/commit/43203371004e035bdb70a00a8dad29a4b657c6c3)입니다. 설정 184개 및 opendbc 기반 차량 목록 329개를 포함합니다. 기기에서 추가된 차량 이름은 내장 목록에 없을 수 있지만 가져온 백업 값은 유지합니다.

서버의 실제 차종별 인기값은 오프라인에서 알 수 없어 표시하지 않습니다. 원본에 설명이 없는 항목에는 임의 설명을 만들지 않았습니다. 주행·로그·터미널의 기기 기능은 데모에서 실행하지 않습니다.

실제 브라우저/휴대폰에서 원본과 같은 화면인지 비교하는 검증은 아직 완료하지 않았습니다. JavaScript 구문 및 내장 데이터 보존을 정적으로 확인했습니다.
